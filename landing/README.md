# EZ Chatbot Landing Page

Static landing page for the public widget demo.

## Stack

- HTML
- CSS
- Vanilla JavaScript

## Run

```bash
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```

## Widget Embed

```html
<script
  src="https://your-landing-domain.com/chat-widget/dist/ez-chat-widget.js"
  data-site-id="SITE_ID">
</script>
```

For local preview inside this repo, `./chat-widget/dist/ez-chat-widget.js` is fine.
